## Предметная область

Приложение «Генератор паролей». Пользователь задаёт параметры генерации:
- длину пароля (количество символов);
- наборы символов, включаемых в пароль (цифры, буквы, спецсимволы);
- количество генерируемых паролей.

## Функциональные требования

1. На главной форме размещена кнопка «Ввести данные».
2. По нажатию на кнопку открывается дополнительное окно для ввода параметров генерации.
3. Последние введённые данные запоминаются и восстанавливаются при повторном открытии окна ввода.
4. После ввода данных на главной форме отображаются:
   - текущие параметры генерации;
   - сгенерированные пароли.
5. При вводе некорректных данных (пустые поля, неверный формат, выход за допустимые диапазоны, не выбран ни один набор символов) выводится сообщение об ошибке.

## Архитектура

Проект построен по паттерну **MVC (Model – View – Controller)** с **активной моделью**:
- **Model** (`PasswordModel`) — хранит параметры генерации и сгенерированные пароли, уведомляет подписчиков об изменениях через механизм слушателей (паттерн «Наблюдатель»).
- **View** (`PasswordGeneratorView`) — главная форма и диалоговое окно ввода, отображает данные и передаёт ввод пользователя контроллеру.
- **Controller** (`PasswordGeneratorController`) — обрабатывает действия пользователя, выполняет валидацию данных и изменяет состояние модели.
